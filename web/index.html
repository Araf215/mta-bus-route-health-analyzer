MTA Route Health Monitor

A live dashboard that tracks what is happening on MTA bus routes using real-time bus data. This version focuses on custom route-health signals, like how many buses are in service, how many are in layover, and how actively buses on the route are moving over time.

Project Overview

This project turns live MTA bus data into a real-time dashboard that shows how a route is performing. It tracks the buses currently on a selected route, highlights which buses are actively in service, identifies layovers, measures movement over a five-minute interval, and summarizes those signals into a Route Health score.
